# Project cover sources

Each project cover in `public/projects/` is rendered from one of these HTML files at 1440×900.
They share `kit.css` (brand gradient, dot grid, window frame), so the set stays uniform.

The `raw/` screenshots and promo video they reference are not committed; recapture them
from the live sites (or the app's promo video) and put them in `covers-src/raw/` to re-render.
Open a file in Chrome at a 1440×900 window and take a screenshot.
